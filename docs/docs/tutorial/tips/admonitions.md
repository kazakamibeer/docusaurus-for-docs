# 注意書きを入れる

補足や注意点を目立たせたいときは、色付きの枠（アドモニション）を使います。

## 書き方の基本

`:::種類` と `:::` で文章を囲みます。

```md
:::note
補足情報を書きます。
:::
```

## 種類

5つの種類があり、それぞれ色とアイコンが違います。

```md
:::note
補足です。知っておくと役に立つ情報を書きます。
:::

:::tip
ヒントです。便利な使い方やコツを書きます。
:::

:::info
お知らせです。関連する情報を書きます。
:::

:::warning
注意です。間違えやすい点を書きます。
:::

:::danger
警告です。データが消えるなど、重大な問題につながる点を書きます。
:::
```

表示例：

:::note
補足です。知っておくと役に立つ情報を書きます。
:::

:::tip
ヒントです。便利な使い方やコツを書きます。
:::

:::info
お知らせです。関連する情報を書きます。
:::

:::warning
注意です。間違えやすい点を書きます。
:::

:::danger
警告です。データが消えるなど、重大な問題につながる点を書きます。
:::

## タイトルを付ける

`:::種類` の後ろにスペースを空けて文字を書くと、枠のタイトルになります。

```md
:::warning 本番環境での作業
本番環境のコマンドは、必ず2人で確認してから実行してください。
:::
```

表示例：

:::warning 本番環境での作業
本番環境のコマンドは、必ず2人で確認してから実行してください。
:::

:::tip 書くときの注意
`:::` の前後には空行を入れてください。
空行がないと、うまく枠にならないことがあります。
:::
