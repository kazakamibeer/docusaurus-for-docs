# 画像を貼る

画面のスクリーンショットや図は、画像ファイルをフォルダに置いて貼り付けます。

## 書き方の基本

画像は `![説明文](画像のパス)` の形で書きます。
リンクの書き方の先頭に `!` を付けた形です。

説明文は、画像が表示できないときに代わりに表示される文字です。何の画像かを短く書きます。

## `img` フォルダを使う方法（おすすめ）

ページと同じフォルダに `img` フォルダを作り、その中に画像を置きます。

```text
docs/docs/tutorial/tips/
├── images.md      ← このページ
└── img/
    └── sample.png ← 貼り付ける画像
```

ページからは、相対パスで画像を指定します。

```md
![サンプル画像](./img/sample.png)
```

表示例：

![サンプル画像](./img/sample.png)

ページと画像が同じ場所にあるので、どの画像がどのページで使われているか分かりやすくなります。
フォルダごと移動しても、リンクが切れません。

## サイト全体で使う画像

ロゴなど、いろいろなページで使う画像は `docs/static/img/` に置きます。
この場合は `/img/` から始まるパスで指定します。

```md
![Docusaurus のロゴ](/img/docusaurus.png)
```

表示例：

![Docusaurus のロゴ](/img/docusaurus.png)

## 画像の大きさを変える

Markdown の書き方では大きさを指定できません。
大きさを変えたいときは、`img` タグを使い、`width` を指定します。

```md
<img src={require('./img/sample.png').default} alt="サンプル画像" width="120" />
```

表示例：

<img src={require('./img/sample.png').default} alt="サンプル画像" width="120" />

`src` の部分は書き方が少し特殊ですが、`./img/sample.png` の部分だけを書き換えれば使えます。

## 画像ファイルのルール

- ファイル名は **半角英数字とハイフン** にします（例：`login-screen.png`）。
- 形式は `png`・`jpg`・`svg`・`gif` が使えます。スクリーンショットは `png` がおすすめです。
- 大きすぎる画像はページの表示が遅くなるため、数 MB を超える場合は縮小してから置いてください。

:::warning パスと大文字・小文字
画像のパスが間違っていると、ビルドでエラーになります。
Windows では大文字・小文字を区別しませんが、公開時のビルド環境では区別します。
`Sample.PNG` と `sample.png` は別のファイルとして扱われるので、ファイル名とパスを完全に合わせてください。
:::
