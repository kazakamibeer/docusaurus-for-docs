# リンクを貼る

## 書き方の基本

リンクは `[表示する文字](リンク先)` の形で書きます。

```md
[Docusaurus 公式サイト](https://docusaurus.io/)
```

表示例：[Docusaurus 公式サイト](https://docusaurus.io/)

## サイト内のほかのページへのリンク

サイト内のページへは、**Markdown ファイルへの相対パス** で書くのがおすすめです。
`.md` まで含めて書きます。

```md
<!-- 同じフォルダのファイル -->
[コードブロックを書く](./code-blocks.md)

<!-- 1つ上のフォルダにあるファイル -->
[はじめに](../intro.md)

<!-- 別のフォルダにあるファイル -->
[ファイルを追加する](../basics/add-file.md)
```

表示例：

- [コードブロックを書く](./code-blocks.md)
- [はじめに](../intro.md)
- [ファイルを追加する](../basics/add-file.md)

`./` は「このファイルと同じフォルダ」、`../` は「1つ上のフォルダ」という意味です。

:::tip ファイルへの相対パスで書く理由
ファイルへのパスで書いておくと、Docusaurus が正しい URL に変換してくれます。
リンク先のファイルが見つからない場合はビルドでエラーになるため、リンク切れにすぐ気付けます。
:::

## 見出しへのリンク

ページ内の見出しには、`#` の後ろに見出しの文字を付けてリンクできます。

```md
<!-- 同じページの見出し -->
[書き方の基本](#書き方の基本)

<!-- ほかのページの見出し -->
[ファイル名のルール](../basics/add-file.md#ファイル名のルール)
```

表示例：

- [書き方の基本](#書き方の基本)
- [ファイル名のルール](../basics/add-file.md#ファイル名のルール)

見出しのリンク先は、ブラウザで見出しにマウスを乗せたときに出る `#` をクリックすると確認できます。
