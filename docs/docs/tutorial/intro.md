# はじめに

## このサイトについて

このサイトは、社内のドキュメントやファイルを共有するためのページです。
手順書、設計書のテンプレート、ハンズオン資料などをここにまとめ、ブラウザから誰でも読めるようにします。

ページの中身はすべて GitHub リポジトリの中の Markdown ファイルです。
ファイルを追加して GitHub に push すると、自動でこのサイトに反映されます。

## Docusaurus とは

このサイトは [Docusaurus](https://docusaurus.io/) というオープンソースのツールで作っています。
Docusaurus は Meta 社が開発しているドキュメントサイト作成ツールで、次の特長があります。

- **Markdown で書ける**：HTML を書かずに、テキストファイルだけでページを作れます。
- **メニューが自動でできる**：フォルダとファイルを置くだけで、左側のメニュー（サイドバー）が作られます。
- **検索しやすい見た目**：見出しの目次、ダークモード、コードの色分けなどが最初から使えます。

できあがったサイトは GitHub Pages で公開しています。
`main` ブランチに push すると GitHub Actions が自動でサイトを作り直し、数分後に反映されます。

## このチュートリアルの内容

このチュートリアルでは、ドキュメントを追加する人向けに、次の内容を説明します。

1. **基本の使い方**：ファイルやフォルダの追加方法、タブの追加方法、公開までの流れ
2. **Tips**：リンク、コードブロック、画像、注意書きなど、よく使う書き方

まずは [ファイルを追加する](./basics/add-file.md) から読み進めてください。
