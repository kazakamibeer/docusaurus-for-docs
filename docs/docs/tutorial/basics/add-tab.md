# タブを追加する

画面上部の「Tutorial」「DL-画像認識ハンズオン」のようなタブを増やす方法です。
テーマごとにタブを分けると、ドキュメントを探しやすくなります。

タブの追加には、次の3つの作業が必要です。

1. ドキュメントを入れるフォルダを作る
2. `docs/sidebars.ts` にサイドバーを追加する
3. `docs/docusaurus.config.ts` にタブを追加する

例として、「業務マニュアル」というタブを追加します。

## 1. フォルダを作る

`docs/docs/` の下に、新しいタブ用のフォルダを作り、最初のページを置きます。

```text
docs/docs/
├── tutorial/
├── image-recognition/
└── manual/                 ← 新しいフォルダ
    └── intro.md            ← 最初のページ
```

```md title="docs/docs/manual/intro.md"
---
sidebar_position: 1
title: 業務マニュアルについて
---

# 業務マニュアルについて

このタブには業務マニュアルをまとめます。
```

## 2. サイドバーを追加する

`docs/sidebars.ts` を開き、新しいフォルダ用のサイドバーを1行追加します。

```ts title="docs/sidebars.ts"
const sidebars: SidebarsConfig = {
  tutorialSidebar: [{type: 'autogenerated', dirName: 'tutorial'}],
  imageRecognitionSidebar: [{type: 'autogenerated', dirName: 'image-recognition'}],
  // highlight-next-line
  manualSidebar: [{type: 'autogenerated', dirName: 'manual'}],
};
```

- `manualSidebar` はサイドバーの名前です。半角英数字で自由に決められます。
- `dirName` には、手順1で作ったフォルダ名を書きます。
- `autogenerated` は「フォルダの中身から自動でメニューを作る」という意味です。

## 3. タブを追加する

`docs/docusaurus.config.ts` を開き、`navbar` の `items` に項目を追加します。

```ts title="docs/docusaurus.config.ts"
navbar: {
  items: [
    {
      type: 'docSidebar',
      sidebarId: 'tutorialSidebar',
      position: 'left',
      label: 'Tutorial',
    },
    // highlight-start
    {
      type: 'docSidebar',
      sidebarId: 'manualSidebar',  // 手順2で決めたサイドバーの名前
      position: 'left',
      label: '業務マニュアル',       // タブに表示される名前
    },
    // highlight-end
  ],
},
```

| 項目 | 意味 |
|---|---|
| `sidebarId` | 手順2で `sidebars.ts` に書いた名前。完全に同じにします |
| `label` | タブに表示される名前 |
| `position` | `left` なら左側、`right` なら右側に表示されます |

タブは `items` に書いた順に左から並びます。

:::warning 名前のずれに注意
`sidebarId` と `sidebars.ts` の名前が1文字でも違うと、サイトの更新が失敗します。
また、フォルダが空のままでもエラーになるため、最低1つはファイルを置いてください。
:::
