## ファイル仕様

| 項目       | 仕様                          |
| ---------- | ----------------------------- |
| 文字コード | UTF-8（BOMなし）              |
| 改行コード | CRLF                          |
| 区切り文字 | カンマ（,）                   |
| 囲み文字   | ダブルクォート（"）           |
| ヘッダー行 | あり（1行目）                 |
| エスケープ | ダブルクォートは2つ重ね（""） |

## 項目定義

- ソート：顧客ID
- NULL・空文字の扱い：未設定の場合は空文字

| No  | 論理項目名 | 物理項目名  | 必須 | 文字種     | 桁数 | 説明               |
| --- | ---------- | ----------- | ---- | ---------- | ---- | ------------------ |
| 1   | 顧客ID     | customer_id | ○    | 半角数字   | 10   | システム内ユニーク |
| 2   | 氏名       | name        | ○    | -          | 50   |                    |
| 3   | 登録日     | created_at  | ○    | YYYY-MM-DD | -    |                    |

## ファイルイメージ

```
customer_id,name,created_at
1000000001,"山田 太郎",2025-01-15
1000000002,"鈴木 花子",2025-03-22
```
