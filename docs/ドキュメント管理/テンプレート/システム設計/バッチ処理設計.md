# バッチ処理設計｛題名はバッチ名とする｝

## 概要

｛このバッチで実現する業務目的を記載する｝

## 実行条件

- 前提条件：先行バッチ完了等
- 排他制御：同一バッチの多重起動禁止等

## 起動引数

| No  | パラメータ名 | 必須 | 文字種      | 桁数 | 説明       |
| --- | ------------ | ---- | ----------- | ---: | ---------- |
| 1   | mode         | ◯    | 1:xxx,2:yyy |    1 | zzz        |
| 2   | targetDate   | -    | YYYYMMDD    |    - | 処理対象日 |

## シーケンス図

```mermaid
sequenceDiagram
    participant Batch as バッチサーバー
    participant DynamoDB as DynamoDB
    participant S3 as S3

    activate Batch

    Batch->>DynamoDB: xxテーブル全件取得
    DynamoDB-->>Batch:

    alt 取得失敗
        Note over Batch: システムエラー
        Batch->>Batch: 処理中断
    end

    loop 全ユーザー分繰り返し
        Batch->>Batch: 出力データ生成
    end

    Batch->>S3: xxファイル出力
    S3-->>Batch:

    alt 出力失敗
        Note over Batch: システムエラー
        Batch->>Batch: 処理中断
    end

    deactivate Batch
```
